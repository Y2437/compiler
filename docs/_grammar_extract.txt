⼀、概要
SysY 语⾔是编译技术实验所完成的编译器的源语⾔，是  C 语⾔的⼀个⼦集。⼀个  SysY 语⾔源程序⽂件中有
且仅有⼀个名为  main 的主函数定义，除此之外包含若⼲全局变量声明、常量声明和其他函数定义。 SysY 语⾔
⽀持  32 位有符号数  int 类型、 8 位⽆符号数  char 类型及其的⼀维数组类型；const 修饰符⽤于声明常量。
SysY 语⾔本⾝没有提供输⼊ / 输出 (I/O) 的语⾔构造， I/O 是以运⾏时库⽅式提供，库函数可以在  SysY 程序中的
函数内调⽤。
函数：函数可以带参数也可以不带参数，参数的类型可以是  int、char 或其⼀维数组类型；函数可以返
回  int、char 类型的值，或者不返回值（即声明为  void 类型）。当参数为  int 或  char 时，按值传
递；⽽参数为数组类型时，实际传递的是数组的起始地址。函数体由若⼲变量声明和语句组成。
变量 / 常量声明：可以在⼀个变量 / 常量声明语句中声明多个变量或常量，声明时可以带初始化表达式。所
有变量 / 常量要求先定义再使⽤。在函数外声明的为全局变量 / 常量，在函数内声明的为局部变量 / 常量。
语句：语句包括赋值语句、表达式语句 ( 表达式可以为空 ) 、语句块、if 语句、while 语句、switch 语
句、break 语句、continue 语句、return 语句。语句块中可以包含若⼲变量声明和语句。
表达式：⽀持基本的算术运算（+、-、*、/、%）、关系运算（==、!=、<、>、<=、>=）和逻辑运算
（!、&&、||），⾮  0 表⽰真、 0 表⽰假，⽽关系运算或逻辑运算的结果⽤  1 表⽰真、 0 表⽰假。算符的
优先级和结合性以及计算规则 ( 含逻辑运算的 “ 短路计算 ”) 与  C 语⾔⼀致。

3. 补充说明
(1) 标识符  Ident
SysY 语⾔中标识符  Ident 的规范如下  ( identifier ) ：
identifier → identifier-nondigit
| identifier identifier-nondigit
| identifier digit
其中，identifier-nondigit 为下划线或⼤⼩写字⺟，digit 为 0 到 9 的数字。
注：请参考  ISO/IEC 9899 http://www.open-std.org/jtc1/sc22/wg14/www/docs/n1124.pdf 第  51 ⻚关于标识符的
定义同名标识符的约定：
全局变量（常量）和局部变量（常量）的作⽤域可以重叠，重叠部分局部变量（常量）优先；
同名局部变量的作⽤域不能重叠，即同⼀个  Block 内不能有同名的标识符（常量 / 变量）；
在不同的作⽤域下， SysY 语⾔中变量（常量）名可以与函数名相同；
保留关键字不能作为标识符。
// 合法样例
int main() {
int a = 0;
{
int a = 1;
printf("%d",a); // 输出  1
}
return 0;
}
// ⾮法样例
int main() {
int a = 0;
{
int a = 1;
int a = 2; // ⾮法！
}
return 0;
}

(3) 数值常量
SysY 语⾔中数值常量可以是整型数  IntConst，其规范如下（对应  integer-const）：
整型常量  integer-const → decimal-const | 0
 decimal-const → nonzero-digit | decimal-const digit
 nonzero-digit 为1⾄9的数字。
注：请参考  ISO/IEC 9899 http://www.open-std.org/jtc1/sc22/wg14/www/docs/n1124.pdf 第  54 ⻚关于整型常量
的定义，在此基础上忽略所有后缀。
(4) 字符常量
SysY 语⾔中字符常量可以是  CharConst，其规范如下：
字符常量  CharConst → '\'' <CharElement> '\''
<CharElement> → <NormalChar> | <EscapeChar>
<NormalChar> → 除  '\''、'\\' 外的可⻅ ASCII 字符，即： ASCII 码范围 [0x20, 0x7E] 内的字
符，但不包含0x27和0x5C
<EscapeChar> → '\\n' | '\\t' | '\\r' | '\\0' | '\\\\' | '\\\''
注：字符常量⽤于表⽰单个字符，其值为对应字符的  ASCII 码值。字符常量可以赋给  char 类型变量，但不能
直接赋给  int 类型变量，除⾮使⽤显式类型转换。
(5) 字符串常量
SysY 语⾔中  StringConst 的定义如下：
<FormatChar> → %d | %c | %s
<NormalChar> → ⼗进制编码为32,33,40-126的 ASCII 字符，'\' （编码 92 ）出现当且仅当
为 '\n'
<Char> → <FormatChar> | <NormalChar>
<StringConst> → '"'{<Char>}'"'
字符串中仅可能会出现⼀种转义字符 '\n'，⽤以标注此处换⾏，其他转义情况⽆需考虑。

4. 难度分级
为了更好的帮助同学们完成编译器的设计，课程组将题⽬难度做了区分。难度等级分为三级： A 、 B 、 C ，难度
依次递减：
C ：最简单的等级，重点考察编译器的基础设计，不包括任何与数组有关的部分，if 与  while 中的条件
表达式也只有⼀个表达式（即不出现  && 和  || ）不考察短路求值的规则，不考察  char 类型与  switch
语句。
B ：在  C 级的基础上，新增数组，包括数组定义，数组元素的使⽤、数组传参等，新增 char 类型与
switch 语句。
A ：在  B 级的基础上，新增复杂条件的运算和判断，要遵守短路求值的规则。
短路求值样例：
int global_var = 0;
int func() {
global_var = global_var + 1;
return 1;
}
int main() {
if (0 && func()){
;
}
printf("%d",global_var); // 输出  0
if (1 || func()) {
;
}
printf("%d",global_var); // 输出  0
return 0;
}

static 关键字
1. static 关键字⽤于修饰静态局部变量，不会在全局变量定义中出现。
2. ⽤  static 修饰的变量声明，即使在声明时未赋初值，编译器也会把它初始化为 0。
3. ⽤  static 修饰的变量声明若有初始值，其初始值保证在编译期内可求出。
4. static 关键字指定的变量只初始化⼀次，并在之后调⽤该函数时保留其状态，离开函数时不会被销
毁。
类型约束
1. 为降低教学复杂度， SysY 语⾔中  int 和  char 是两种不同的基本类型，不允许直接进⾏混合运算，但
允许进⾏显式的类型转换（详⻅下），转换后类型⼀致则可以混合运算。
2. 当表达式中出现多类型（包括  int/char/int[]/char[]/void 任意类型）混合运算（且未正确使⽤
显式类型转换）时，应报类型不匹配错误。
3. char 类型变量可以单独使⽤，也可以进⾏  char 类型之间的运算，运算结果仍为  char 类型。
4. int 类型变量可以单独使⽤，也可以进⾏  int 类型之间的运算，运算结果仍为  int 类型。
5. 在赋值语句中，左值和右值的类型必须⼀致，即  int 变量只能赋  int 值，char 变量只能赋  char 值。
6. 数组下标、数组⻓度只能使⽤  int 类型的表达式，不能使⽤  char 类型的表达式。
7. 函数参数传递时，实参类型必须与形参类型完全⼀致。
8. 函数返回值类型必须与函数声明的返回类型⼀致。
9. char 类型定义为  unsigned char（⽆符号 8 位整数），取值范围为  0 ~ 255。此定义符合  ISO/IEC 9899 C
语⾔标准中  unsigned char 的规范。
10. char 类型运算发⽣溢出时，采⽤  模 256 回绕（ wrap-around ） ⽅式处理。例如：255 + 1 的结果为
0，0 - 1 的结果为  255。此⾏为符合  C 语⾔标准中  unsigned 整数的溢出处理规则。
11. char 类型变量的值范围为  0 ~ 255 ，其中  0 ~ 127 对应标准  ASCII 字符，可通过字符常量赋值；128 ~
255 只能通过运算溢出或直接赋数值产⽣。printf 使⽤  %c 输出时，编译器只需确保正确传递  char 值
给  printf 函数，输出结果由运⾏环境决定。测试⽤例应避免使⽤  %c 输出  128 ~ 255 的值。
12. 当字符串常量⽤于初始化  char 或  char[] 时，应将字符串的字节序列（按转义处理后得到的字节）逐
字节复制到数组中；若数组⻓度⼤于字符串⻓度，则剩余元素置  0 ；若数组⻓度  N ⼩于字符串⻓度，则
只复制字符串的前  N 个字节，不要额外添加  \0。
13. 显式类型转换语法  (BType) UnaryExp ⽤于将基本类型表达式进⾏显式转换。被转换的表达式
UnaryExp 的类型必须是基本类型  int 或  char。转换后表达式的类型为⽬标基本类型  BType。显式类
型转换可以解决由于类型不匹配导致的混合运算、赋值、传参或返回等错误。
注：打印时，%d ⽤于输出  int，%c ⽤于输出  char。当向运⾏时库传递  char 时，编译器应确保按⽬标平台
ABI 正确传递  8 位⽆符号值（通常会经过整型提升或按  ABI 要求扩展到机器整型）。测试⽤例中尽量使⽤  ASCII
范围（ 0..127 ）的字符常量和字符串，以避免平台编码差异影响结果。
注：此约束旨在在语义阶段时就建构类型系统，避免在中间代码⽣成时再对前端部分进⾏调整。

1. FuncDef 表⽰函数定义。其中的  FuncType 指明返回类型。当返回类型为  int 时，函数内所有分⽀都

语句块  Block
1. Block 表⽰语句块。语句块会创建作⽤域，语句块内声明的常量和变量的⽣存期在该语句块内。

句块尾结束，它隐藏语句块外的同名变量或常量。
3. 为了降低开发难度，保证所有测试程序中有返回值的函数  Block 的最后⼀句⼀定会显式的给出  return 语
句，否则就当作 “ ⽆返回语句 ” 的错误处理。 同时，同学们编写上传的样例程序时，也需要保证这⼀点。
4. main 函数的返回值只能为常数 0 。

1. Stmt 中的  if 类型语句遵循就近匹配，即，在没有使⽤⼤括号明确界定代码块范围的情况下，⼀个

2. 单个  Exp 可以作为  Stmt。这个  Exp 会被求值（这可能产⽣副作⽤），但是所求的值会被丢弃。
3. while 语句中，Cond 为循环条件，Stmt 为循环体。当  Cond 为真时，执⾏  Stmt，否则跳出循环。

5. switch 语句中的每个  case 后必须有  Number 作为匹配值。Number 的类型必须与  switch 表达式

型， Number 必须为  char 常量（CharConst）。
6. switch 语句中最多可以有⼀个  default 语句，当所有  case 都不匹配时执⾏  default 后的语句。
7. break 语句可以出现在循环语句（while）或  switch 语句中，⽤于跳出循环或  switch 结构。
8. continue 语句只能出现在循环语句（while）中，⽤于跳过当前迭代，继续下⼀次循环。
9. switch 语句中，break ⽤于跳出  switch 结构，若某个  case 后没有  break，则继续执⾏下⼀个

左值  LVal
1. LVal 表⽰具有左值的表达式，可以为变量或者某个数组元素。
2. 当  LVal 表⽰数组时，⽅括号个数必须和数组变量的维数相同（即定位到元素）。
3. 当  LVal 表⽰单个变量时，不能出现后⾯的⽅括号。
Exp 与  Cond
1. Exp 在  SysY 中代表算术表达式； Cond 代表条件表达式，故它定义为  LOrExp 。前者的单⽬运算符中
不出现 '!' ，后者可以出现。
2. LVal 必须是当前作⽤域内、该  Exp 语句之前有定义的变量或常量；对于赋值号左边的  LVal 必须是变
量。
3. 函数调⽤形式是  Ident '('' FuncRParams ')'，其中的  FuncRParams 表⽰实际参数。实际参数
的类型和个数必须与  Ident 对应的函数定义的形参完全匹配。
4. SysY 中算符的优先级与结合性与  C 语⾔⼀致，在上⾯的  SysY ⽂法中已体现出优先级与结合性的定义。
⼀元表达式  UnaryExp
1. 相邻两个  UnaryOp 不能相同，如  int a = ++-i; ，但是  int a = +-+i; 是可⾏的。
2. UnaryOp 为  ! 只能出现在条件表达式中。
3. 显式类型转换  (BType) UnaryExp 中的  BType 只能是基本类型  int 或  char。
常量表达式  ConstExp
1. ConstExp 在  SysY 中代表可在编译期求值的表达式，可以是  int 型表达式或  char 型表达式。
2. ConstExp 在编译期内是可被求值的，且需要符合  C 语⾔标准中 “ 整型常量表达式（ integer constant
expression ） ” 的约束：其操作数只能为整型常量、字符常量，不能访问其它变量、不能进⾏函数调⽤（即
使访问的变量、进⾏的函数调⽤理论上是能在编译期求值的）。
3. ConstExp 中不能出现  int 和  char 类型的混合运算，必须保证类型⼀致性（如果使⽤了显式类型转
换，则按照转换后的⽬标类型进⾏⼀致性检查）。

数组定义时指定各维⻓度（此时必须是  int 型常量表达式）
常量定义时的初始值
