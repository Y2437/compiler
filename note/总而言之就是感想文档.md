# 编译器总体设计

## 总体结构

首先我做的是CPP的MIPS编译器

我想的是,既然这个符号表管理和错误处理贯穿整个编译过程的始终,然后又有五个主要逻辑流程

```cpp
    {
```

```cpp
        int ch=get_cur();
        int nt=get_next();
        reset_token();
        if(ch=='\"'){//STRCON
            tokenList.push_back(get_const_str_token());
        }else if(ch=='\''){//CHARCON
            tokenList.push_back(get_const_char_token());
        }else if(isdigit(ch)){ //INTCON
            tokenList.push_back(get_const_int_token());
        }else if(isalpha(ch)||ch=='_'){  //Ident or KW

            skip_line();
        }else if(ch=='/'&& nt=='*') {//block comment
            skip_block();
        }else{  //OPERA
            tokenList.push_back(get_operator_token());
        }
        
    }
}
```

## 总体设计

首先是看见原来的这个结构有一个不太合理的地方

这样就可以解耦了

然后就是关于语法分析本身的设计

首先,题目要求的输出方式其实就是对于语法树的后序遍历的输出

既然都要这样输出了,我就考虑直接建一个语法树,然后遍历这个树来进行输出

那么就要考虑这个语法树应当如何建立

## 语法树的建立

首先,是这个语法节点的存储问题,考虑到可用性和工程化,我使用unique_ptr来做这个节点的存储,并使用专门的分配函数

```cpp
ParToken * Parser::make_ParToken(ParTokenKind kind){
    parTokenPool.push_back(make_unique<struct ParToken>());
    ParToken * node = parTokenPool.back().get();
    node->type=kind;
    return node;
} 
```

这样每次新建节点时,只要调用这个make就行了

然后这些节点会随着Parser类的释放而释放,是内存安全的

其次,是这个语法树的建立问题,我没有使用Optional的那些语法特性,就只是给每个语法成分写了一个方法:
```cpp
// 常量声明 ConstDecl → 'const' BType ConstDef { ',' ConstDef } ';' // i
ParToken * Parser::parse_ConstDecl(){
    ParToken * node = make_ParToken(ConstDecl);
    match(node,CONSTTK);
    node->add(parse_BType());
    node->add(parse_ConstDef());
    while (check(COMMA))
    {
        match(node,COMMA);
        node->add(parse_ConstDef());
    }
    match(node,SEMICN);
    return node;
}
```

范式就是:

1. 新建语法节点
2. 检查可选成分
3. 挂载叶子节点来匹配字符(match本身包含挂载逻辑)
4. 挂载子树节点来匹配语法成分
5. 返回语法节点(这样就可以递归构造树了)

然后关于语法成分的检测,分为一下几个情况

- 是必要的字符,使用match匹配,没有则报错
- 是可选的语法成分或字符,使用if
- 是可以重复多次的成分或字符,使用while
- 对于语法成分,使用专门的is_xxxxx_ahead函数处理,这个函数通过匹配共同前缀后的字符来判断语法成分

```cpp
const LexToken & Parser::get_cur(){
    return get_offset_next(0);
}
const LexToken & Parser::get_next(){
    return get_offset_next(1);
}
const LexToken & Parser::get_offset_next(int offset){
    static const LexToken eofToken{Eof,string(),0};   //这里是因为返回引用,所以需要一个静态变量
    if(curPos>=0&&curPos+offset<lexTokenList.size()){      //本身位置就不可以违法,所以>=0
        return lexTokenList[curPos+offset];
    }
    return eofToken;
}
void Parser::move_backward(){
    if(curPos>0) curPos--;
}
void Parser::move_forward(){
    if(curPos<lexTokenList.size()) curPos++;
}
void Parser::match(ParToken * father, LexTokenKind tar){
    if(get_cur().tokenType==tar){
        ParToken * node =make_ParToken(Leaf);
        node->lexToken=&get_cur();
        father->add(node);      
        move_forward();
    }else if(get_cur().tokenType==LexError){
        move_forward();
    }else {
        errorController->register_ijk(tar,get_prev_line());
    }
}

bool Parser::check(LexTokenKind tar,int offset=0){
    if(tar==get_offset_next(offset).tokenType) return true;
    return false;
}
bool Parser::check_any(initializer_list<LexTokenKind> list,int offset=0){
    for(auto & kind :list){
        if(get_offset_next(offset).tokenType==kind) return true;
    }
    return false;
}
```

check只检查不消耗,match检查并消耗,不匹配则报错
